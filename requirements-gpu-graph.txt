# torch_cluster 1.6.3+pt22cu121. The --find-links index below is torch-version-specific
# and is what selects those exact builds; torch_scatter/torch_cluster are left unpinned
# here since it is the only build available there anyway.
#
# timm is included for parity with the cluster's all-in-one image, not because any
# graph config currently uses a transformer backbone.
#
#   pip install -r requirements-gpu-graph.txt
